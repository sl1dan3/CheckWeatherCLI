# CheckWeatherCLI 🌤️

A simple command-line application for getting current weather information.

Простое консольное приложение для получения текущей информации о погоде.

---

## 🇬🇧 English

### About

**CheckWeatherCLI** is a simple CLI application built with Node.js.

The application retrieves current weather information and displays it directly in the terminal.

### Features

- 🌍 Displays country and city
- 🕐 Displays current date and time
- 🌡️ Displays temperature
- 💨 Displays wind speed
- ⚡ Simple command-line interface

### Requirements

- Node.js 18 or higher
- npm

### Installation

Install the package globally using npm:

```bash
npm install -g checkweathercli
```

### Usage

Run the application with:

```bash
weather
```

### Example

```text
================
CheckWeatherCLI
================

Netherlands, Amsterdam
2026-08-22 18:45

Temperature: 18°C
Wind speed: 12 km/h
```

### Technologies

- JavaScript
- Node.js
- Fetch API
- REST API
- npm
- ES Modules
